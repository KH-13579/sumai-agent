# 概算見積AIを追加

## 概要

要件定義 FR-05 に対応する概算見積AIを追加しました。金額計算はLLMではなく静的単価テーブルと補正係数を使う決定論的ツールとして実装しています。

## 変更内容

- 概算見積の入出力スキーマを追加
- 坪単価、構造・階数・仕様係数、設備費の静的データを追加
- 概算レンジ、内訳、予算超過、削減候補を返す計算エンジンを追加
- `POST /api/estimate` を追加
- ブラウザUIに見積入力・結果表示を追加
- 再現性、計算、予算超過、入力検証のテストを追加
- READMEとデモ手順を更新

## 確認方法

```bash
cd sumai-agent
python -m pytest tests -v
python run.py
```

ブラウザで `http://localhost:8000` を開き、右側の「概算見積AI」から確認できます。

## 留意事項

研究用モックの概算であり、契約・発注に使える正式見積ではありません。費用範囲、根拠年度、未反映費用、免責をAPI結果へ明示しています。
