# 見積AI 提出説明書

## 1. 目的

住宅AIエージェントの間取り案に対し、延床面積、構造、階数、仕様、追加設備を入力として、説明可能で再現可能な概算建設費を返す。要件定義の FR-05、FR-06、FR-07、NFR-05 に対応する。

## 2. 設計判断

見積の金額計算は LLM に任せない。静的テーブルと算式による `estimate_calculator.py` が計算し、将来オーケストレーターAIが結果の説明や条件調整に利用する。これにより、ハルシネーション、計算揺れ、API停止によるデモ失敗を避ける。

```text
利用者入力
  → 入力検証（Pydantic）
  → 坪換算
  → 基準坪単価 × 構造係数 × 階数係数 × 仕様係数
  → 設備費加算
  → ±10%の概算レンジ
  → 予算超過判定・削減候補
  → 根拠、前提、免責を含むJSON
```

## 3. 主なファイル

| ファイル | 役割 |
|---|---|
| `app/schemas/estimate.py` | 入出力スキーマ、入力制約 |
| `app/data/estimate_rates.json` | 基準単価、係数、設備費、出典 |
| `app/tools/estimate_calculator.py` | 決定論的計算エンジン |
| `app/api/chat.py` | `POST /api/estimate` |
| `frontend/index.html` | 見積入力・結果表示UI |
| `tests/test_estimate_agent.py` | 再現性、予算超過、API、入力検証テスト |

## 4. デモ手順

1. アプリを起動し、`http://localhost:8000` を開く。
2. 右側の「概算見積AI」に、延床面積100㎡、建物予算4,000万円、木造、2階、標準を設定する。
3. 「計算する」を押し、概算レンジ、中心値、予算内判定、免責を確認する。
4. 構造をRC造、仕様をプレミアム、追加設備をすべて選択して再計算する。
5. 予算超過表示へ変わることを確認する。
6. Swagger UI `http://localhost:8000/docs` の `POST /api/estimate` で、JSONの内訳、削減候補、出典、前提を説明する。

## 5. API入力例

```json
{
  "floor_area_sqm": 100,
  "structure": "wood",
  "floors": 2,
  "grade": "standard",
  "equipment": ["solar_4kw"],
  "budget_yen": 40000000
}
```

## 6. 算定範囲と制約

- 基準は住宅金融支援機構「フラット35利用者調査」の注文住宅データを参照した研究用静的値である。
- 土地費、個別敷地、地域差、設計・申請、地盤改良、外構、登記、税、融資費用は含めない。
- 係数・設備単価はモック用であり、本番利用前にデータ年度、費用範囲、地域別・構造別区分を再設計する。
- 契約、融資、発注の判断には使わず、建築士・施工会社の正式見積を必要とする。

## 7. テスト

```bash
python -m pytest tests/test_estimate_agent.py -v
python -m pytest tests -v
```

合格条件は、同一入力の結果一致、基準ケースの計算一致、予算超過と削減候補の出力、異常入力のHTTP 422応答である。
